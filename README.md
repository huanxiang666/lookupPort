# lookupPort — 端口扫描工具

快速扫描局域网/主机的开放端口。**GUI 图形界面 + 命令行双模式**，纯标准库，无需安装第三方依赖。

> 重构自早期版本：修复了"一次起几百个线程导致系统卡死"、"取消按钮无效"、"非法输入直接崩溃"等问题。

## 功能

- 扫描指定 IP / 网段的开放端口
- 线程池并发（默认 100，可调），速度快且不拖垮系统
- **真正的取消**：扫描中途可随时停止
- 支持三种目标格式：
  - 单个 IP：`192.168.1.1`
  - IP 前缀：`192.168.1.`（扫 1~254）
  - CIDR 网段：`192.168.1.0/24`
- 可指定单个端口，或留空扫描 25 个常用端口
- 结果按 IP 数字顺序排列

## 环境要求

- Python 3.8+
- 无第三方依赖（只用标准库）
- GUI 模式需要 tkinter（Windows/macOS 自带；Linux 需 `sudo apt install python3-tk`）

## 使用

### 图形界面（双击或无参数运行）

```bash
python main.py
```

在界面填目标、端口（留空扫常用端口）、超时，点"开始扫描"。

### 命令行

```bash
# 扫描 192.168.1 网段的 80 端口
python main.py 192.168.1. -p 80

# 扫描某台主机的常用端口
python main.py 192.168.1.100

# 扫描整个 /24 网段的常用端口，200 并发
python main.py 192.168.1.0/24 -w 200

# 自定义超时
python main.py 10.0.0.1 -p 3306 -t 2.0
```

### 参数说明

| 参数 | 说明 | 默认 |
|---|---|---|
| `target` | 目标：单IP / 前缀 / CIDR 网段 | 必填 |
| `-p, --port` | 单个端口号 | 留空扫 25 个常用端口 |
| `-t, --timeout` | 每次连接超时（秒） | 1.0 |
| `-w, --workers` | 并发线程数 | 100 |
